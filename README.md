# 🍕 Ki Pizza — Site Bio

## 📌 Sobre o Projeto

Este projeto consiste em um **site bio** desenvolvido para a marca **Ki Pizza**, com foco em identidade visual forte, experiência mobile-first e narrativa de marca diferenciada.

O site foi pensado para apresentar:

* A unidade principal em funcionamento em **Jaru (RO)**
* A nova unidade em pré-lançamento em **Rolim de Moura (RO)**
* Acesso rápido ao WhatsApp
* Localização no Google Maps
* Cardápio digital via app **Anota Aí**

---

## 🎯 Objetivo

Servir como uma **central de conversão rápida e experiência de marca**, permitindo que o cliente:

* fale diretamente com a equipe
* encontre a localização da unidade ativa
* acesse o cardápio digital
* acompanhe a chegada da nova unidade

Tudo isso através de uma interface leve, rápida e extremamente intuitiva no mobile.

---

## ⚙️ Tecnologias Utilizadas

Este projeto foi desenvolvido com foco em performance e sofisticação visual utilizando:

* Vite
* TypeScript
* HTML5
* CSS3

---

## 📱 Responsividade

O projeto foi pensado prioritariamente para dispositivos móveis, garantindo excelente experiência em:

* Smartphones
* Tablets
* Notebooks
* Desktop

A abordagem é totalmente **Mobile First**, com comportamento adaptativo em todas as seções.
